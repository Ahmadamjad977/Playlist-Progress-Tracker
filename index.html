    Settings

    Account and sync

    Sign in to keep your playlists and progress in your account, so they appear on every device where you sign in. Without signing in, everything stays in this browser only.

    Signed in as

    Your YouTube API key is not synced. Paste it once on each device where you import playlists.

    YouTube Data API key

    Importing playlists needs your own free YouTube Data API v3 key. The key is stored only in this browser (LocalStorage) and is sent only to Google. It is not part of the source code.

    How do I get an API key?
    1. Open the Google Cloud Console and create a project.
    2. Enable YouTube Data API v3 for that project.
    3. Go to Credentials, then Create credentials, then API key.
    4. Restrict the key to the YouTube Data API, and to your website address if you deploy this app.
    5. Paste the key above and choose Save key.

    Your data

    Playlists and progress are saved in this browser. When you are signed in they are also saved in your account. Removing them cannot be undone.

    Backup and move to another device

    A backup file is a manual alternative to signing in. Export one here and import it on another device or browser. The backup does not include your API key.

    About progress tracking

    Watching a video on YouTube does not update this app. Tick a video yourself when you finish it.

    Progress is calculated by time: completed video length divided by total playlist length. A 60 minute video counts more than a 5 minute video.
